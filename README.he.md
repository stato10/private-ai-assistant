# עוזר מקומי

[English](README.md) · **עברית**

עוזר AI אישי ל־Windows. הממשק בעברית, והצ׳אט רץ על Qwen דרך Ollama ו־FastAPI במחשב עצמו. השימוש אינו כרוך במנוי, בתשלום לפי הודעה או בחשבון AI חיצוני. לאחר ההתקנה אפשר לשוחח גם בלי חיבור לאינטרנט.

## הפעלה במחשב הזה

פתחו שני חלונות PowerShell בתיקיית הפרויקט. בחלון הראשון הפעילו את Ollama והשאירו אותו פתוח.

```powershell
& .\scripts\ollama.ps1 serve
```

בחלון השני, בפעם הראשונה צרו מפתח ושמרו אותו במנהל הסיסמאות שלכם. הפקודה הבאה מציגה אותו רק במסוף המקומי שלכם.

```powershell
& .\.venv\Scripts\python.exe -c "import secrets; print(secrets.token_urlsafe(32))"
```

הפעילו את השרת והזינו את אותו המפתח כשהסקריפט מבקש אותו. לאחר מכן פתחו את [הצ׳אט המקומי](http://127.0.0.1:8765/) והזינו את המפתח גם בדפדפן.

```powershell
& .\scripts\start.ps1
```

השאירו את שני החלונות פתוחים בזמן השימוש. לעצירה לחצו Ctrl+C בחלון FastAPI ואז בחלון Ollama. אם מתקבלת הודעה שהפורט 11434 כבר תפוס, סגרו את מופע Ollama הקיים או המשיכו עם המופע המקומי שכבר נטען לפי ההגדרות של הפרויקט.

אם כבר רץ במחשב Ollama עם תיקיית מודלים אחרת, הגדירו `$env:GLASSOS_OLLAMA_PORT = '11436'` בשני החלונות לפני הפעלת הסקריפטים. כך שני השרתים משתמשים באותו מופע Ollama של הפרויקט.

בחרו מודל ליד כפתור השליחה. הרשימה מציגה את המודלים הנתמכים שמותקנים ב־Ollama בזמן הכניסה. אפשר להחליף מודל גם באמצע שיחה. המודל שתבחרו יענה להודעה הבאה ויקבל את ההקשר האחרון של השיחה. בטעינה ראשונה של מודל התשובה עשויה להתעכב.

בבורר, **Liquid AI LFM2.5 · 8B** ו־**Qwen 3.5 · 9B** יכולים להפעיל מחשבון מקומי. כשמודל מפעיל אותו, הצ׳אט מציג את הביטוי שהמודל בחר ואת תוצאת המחשבון. כך אפשר לוודא שהביטוי מתאים לשאלה. המחשבון תומך בחיבור, חיסור, כפל, חילוק וסוגריים.

לחצו על ״שיחה חדשה״ כדי לפתוח נושא נוסף. אפשר לחזור לשיחות קודמות מהסרגל כל עוד הדף פתוח והצ׳אט פתוח לשימוש. Enter שולח הודעה ו־Shift+Enter מוסיף שורה. נעילה או רענון הדף מוחקים את השיחות מהזיכרון.

## התקנה מחדש

במחשב Windows עם Python 3.12, התקינו את התלויות בתיקיית הפרויקט.

```powershell
python -m venv .venv
& .\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
```

הורידו את ארכיון Windows AMD64 מהאתר הרשמי של Ollama וחלצו לתיקייה `.runtime/ollama` כך שהקובץ `ollama.exe` יהיה ישירות בתוכה. הסקריפט תומך גם ב־`ollama.exe` מתוך PATH. הפעילו `scripts/ollama.ps1 serve` בחלון הראשון, ובחלון השני הורידו את המודל פעם אחת.

```powershell
& .\scripts\ollama.ps1 pull
```

המודל נשמר ב־`.runtime/models`. הורדת התוכנה, התלויות והמודל דורשת חיבור לאינטרנט. הצ׳אט לאחר ההתקנה פועל מקומית. [Ollama](https://ollama.com/download/windows) · [Qwen3.5](https://ollama.com/library/qwen3.5)

## API מקומי

| נקודת קצה | שימוש |
| --- | --- |
| `GET /healthz` | בדיקת חיות של FastAPI |
| `GET /api/v1/session` | בדיקת מפתח גישה. הצלחה מחזירה 204 |
| `GET /api/v1/models` | רשימת המודלים המקומיים המותקנים ובחירת ברירת המחדל |
| `POST /api/v1/chat` | תשובת המודל ומדדי זמן ויצירת טוקנים |

שלחו לנתיבי ה־API כותרת `Authorization: Bearer <token>` ולצ׳אט גם `Content-Type: application/json`. גוף דוגמה

```json
{"messages":[{"role":"user","content":"מה ההבדל בין RAM ל-VRAM?"}]}
```

שיחה מרובת הודעות משתמשת בתפקידים `user` ו־`assistant` לסירוגין ומסתיימת בהודעת משתמש. השרת מקבל עד 9 הודעות, עד 1,500 תווים להודעה ועד 2,400 תווים יחד. הוא מעבד דור אחד בכל פעם. שגיאות 401, 413, 415, 422, 429, 503 ו־504 מחזירות קוד קריא ב־`detail`.

FastAPI ו־Ollama מאזינים ב־`127.0.0.1`. הגישה לענן של Ollama כבויה. השרת לא שומר שיחות. הדפדפן שומר את המפתח וההודעות בזיכרון הדף, והיסטוריית השיחה הרלוונטית נשלחת מחדש בכל הודעה. הסקריפטים מכוונים למשתמש יחיד במחשב.

`glassos/provider.py` מגדיר ממשק לספק המודל. שכבת התצוגה מתקשרת רק עם ה־API, כך שאפשר להוסיף ספק או נתיב נוסף בלי לשנות את ממשק הצ׳אט.

## בדיקות

```powershell
& .\.venv\Scripts\python.exe -m pytest -q
```

לבדיקה עם המודל האמיתי השאירו את Ollama פתוח ועצרו את FastAPI אם הוא רץ. הבדיקה מפעילה שרת זמני עם מפתח אקראי, בודקת את ה־API ואת תוכן הצ׳אט, מודדת ביצועים, ואז עוצרת את השרת הזמני.

```powershell
& .\.venv\Scripts\python.exe scripts/smoke.py
```

דגימות GPU נשמרות ב־`.runtime/gpu.csv`. ראו [תוצאות בדיקה](RESULTS.md).
